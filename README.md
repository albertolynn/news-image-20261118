A Node program that draws a one-page newspaper summing up the world news of Wednesday 18 November 2026 — masthead with the date, a lead story with a drawn scene, four panels and a news ticker — entirely in code (its own PNG encoder, rasteriser and vector stroke font, no image assets), and writes it as a 1024×1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
